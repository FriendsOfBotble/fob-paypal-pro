# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2024-12-30

### Added

- Initial release
- PayPal Smart Buttons integration for inline checkout
- Webhook support for real-time payment status updates
- Customizable button options (layout, color, shape, label)
- Multi-currency support with auto USD conversion
- Full and partial refund support from admin panel
- Payment details view in admin order page
